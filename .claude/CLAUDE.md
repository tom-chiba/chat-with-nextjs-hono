# 作業の進め方

- こまめに git commit すること
- コードベースの修正を入れる際には必ず新たにブランチを切ってから作業を行うこと
- main ブランチへの直接 push はせず、 PR を出してレビューしてからマージすること
- push 前の修正分に関しては amend や rebase も活用して過去の commit を改変し、 Git tree をきれいに保つこと
