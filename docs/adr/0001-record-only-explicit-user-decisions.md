# 0001: ADR にはユーザーが明示的に意思決定した内容のみを記録する

- ステータス: 採択
- 日付: 2026-06-21

## 背景

ADR は、後から設計判断の理由を確認できるようにするための記録である。

一方で、AI や実装者が推測で既存の技術選定や設計意図を補完すると、実際には決定されていない内容まで決定事項として残ってしまう。そのため、ADR に記録する対象を明確にする必要がある。

## 決定

ADR には、ユーザーが明示的に意思決定した内容のみを記録する。

AI や実装者の推測で意思決定を補完しない。まだ決定されていない内容は、ADR ではなく Issue / Discussion / TODO として扱う。

## 影響

ADR を作成する前に、その内容がユーザーによって明示的に決定済みかを確認する。

既存の技術スタックや実装内容についても、ユーザーが意思決定として明示していない限り、ADR として後付けで記録しない。
